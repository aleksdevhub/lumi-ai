# Чаты LUMI на этом ПК

В SSMS выберите ядро СУБД, сервер `(localdb)\MSSQLLocalDB` и проверку подлинности Windows. Сообщения находятся в `LumiChats → Таблицы → dbo.ChatMessages`. Поле DialogId объединяет сообщения диалога, TelegramUserId определяет владельца.

Откройте в Telegram «Профиль → Синхронизация с ПК». Код находится в файле `%LOCALAPPDATA%\LumiChats\pair.txt` на настроенном компьютере. Введите его на каждом своём устройстве. После привязки синхронизация запускается при новых сообщениях и возвращении в приложение. Кнопка «Синхронизировать» запускает её вручную. Очистка истории на телефоне отключает синхронизацию и удаляет локальные копии. Архив SQL сохраняется.

ПК должен быть включён и подключён к интернету. Для запуска клиента после перезагрузки откройте PowerShell под тем же пользователем Windows и выполните:

```powershell
& "$env:LOCALAPPDATA\LumiChats\start.ps1"
```

Клиент создаёт исходящее WSS-соединение с Cloudflare. Worker проверяет подпись Telegram и код привязки. SQL Server принимает запросы через локальное подключение Windows. Файлы pc.txt и pair.txt держите на своём ПК. Репозиторий содержит только их проверочные хеши.
